# All gestures and their default commands

Every gesture the add-on recognises, as listed in NVDA Settings, Trackpad Gestures category, Gestures tree. "Nothing" means the gesture has no command yet; you can give it one in settings. A zone gesture with no command of its own does the same as the normal gesture.

## One finger

### Taps, swipes and holds

| Gesture | Default command |
| --- | --- |
| Tap | Speaks the current item |
| Double tap | Activates the current item |
| Triple tap | Reports formatting (font, style) at the cursor |
| Double tap and hold | Opens the context menu (like long press) |
| Swipe up | Moves back by the current reading control |
| Swipe down | Moves forward by the current reading control |
| Swipe left | Moves to the previous item |
| Swipe right | Moves to the next item |

### Two-part swipes (angular)

| Gesture | Default command |
| --- | --- |
| Swipe up then down | Selects the next reading control |
| Swipe up then left | Shows the desktop (home) |
| Swipe up then right | Reads the status bar (page, word count, cell) |
| Swipe down then up | Selects the previous reading control |
| Swipe down then left | Goes back |
| Swipe down then right | Opens the NVDA menu |
| Swipe left then up | Switches to the previous app |
| Swipe left then down | Undoes (Control+Z) |
| Swipe left then right | Switches between browse mode and focus mode |
| Swipe right then up | Redoes (Control+Y) |
| Swipe right then down | Opens notifications |
| Swipe right then left | Opens the elements list (headings, links, comments) |

### Zones near the edges

| Gesture | Default command |
| --- | --- |
| Double tap near the top edge | Nothing of its own (does the same as double tap) |
| Double tap near the bottom edge | Nothing of its own (does the same as double tap) |
| Double tap near the left edge | Nothing of its own (does the same as double tap) |
| Double tap near the right edge | Nothing of its own (does the same as double tap) |

### Edge swipes (system panels)

| Gesture | Default command |
| --- | --- |
| Swipe down from the top left corner | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe down from the top edge | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe down from the top right corner | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe up from the bottom left corner | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe up from the bottom edge | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe up from the bottom right corner | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe right from the left edge | Goes to the system panel item at that edge; the same swipe again opens it |
| Swipe left from the right edge | Goes to the system panel item at that edge; the same swipe again opens it |

## Two fingers

### Taps, swipes and holds

| Gesture | Default command |
| --- | --- |
| 2-finger tap | Stops speech |
| 2-finger double tap | Plays or pauses media |
| 2-finger triple tap | Turns selection mode on or off |
| 2-finger swipe up | Scrolls forward (Page Down) |
| 2-finger swipe down | Scrolls back (Page Up) |
| 2-finger swipe left | Goes to the next tab |
| 2-finger swipe right | Goes to the previous tab |
| 2-finger long press | Returns to the application you are working in, and to its document, sheet or list |

### Zones near the edges

| Gesture | Default command |
| --- | --- |
| 2-finger double tap near the top edge | Goes to the menu bar or ribbon (Alt) |

| 2-finger double tap near the right edge | Goes to the system tray |
| 2-finger long press near the top edge | Nothing of its own (does the same as 2-finger long press) |
| 2-finger long press near the bottom edge | Nothing of its own (does the same as 2-finger long press) |
| 2-finger long press near the left edge | Nothing of its own (does the same as 2-finger long press) |
| 2-finger long press near the right edge | Nothing of its own (does the same as 2-finger long press) |

## Keyboard

| Key | Command |
| --- | --- |
| NVDA+Shift+G | Turns trackpad gestures on or off |

## Commands with no gesture by default

- **Navigation:** Speaks the current reading control
- **Reading:** Reads the current line; Reads the selected text; Recognises the text on screen (OCR)
- **Editing:** Cuts (Control+X); Selects all (Control+A)
- **Information:** Speaks the time and date; Speaks the battery status; Reads the clipboard
- **Media and volume:** Next track; Previous track; Turns the volume up; Turns the volume down; Mutes or unmutes the volume
- **Speech:** Changes the speech mode (talk, beeps, off)
